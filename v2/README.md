# AVL 树动画演示（重写版）

在 [`v1/`](../v1/) 旧版（D3 v3 + jQuery + Bootstrap，2021 年）的基础上重写的一版：
**零第三方依赖**，用原生 SVG 渲染，算法与动画彻底解耦，支持暂停、单步、回看，并同步高亮伪代码。

## 运行

直接用浏览器打开 `index.html` 即可。没有构建步骤、没有 CDN 请求，`file://` 下也能跑
（脚本都是传统 `<script>`，刻意不用 ES Module，避免本地打开时的跨域限制）。

## 文件结构


## 设计要点

### 1. 算法只产出快照，不碰 DOM

`avl.js` 里每次增删查都会记录一串 `step`：

```js
{
  tree,          // 这一步的完整树快照（含 id / key / height / bf）
  focus,         // 当前访问的节点
  pathIds,       // 已经走过的路径，用于高亮连线
  matched,       // 命中 / 找到的节点
  inserted,      // 新插入的节点（整个操作期间保持高亮）
  removed,       // 即将摘掉的节点
  rotation,      // { type: 'LL' | 'LR' | 'RR' | 'RL', at }
  line,          // 当前执行的伪代码行
  message,       // 这一句话解释
}
```

节点带唯一 `id`，所以旋转换位、后继替换（key 会被覆盖）都不会让高亮串到别的节点上。

### 2. 渲染层只认快照

- 布局：**中序遍历确定 x**（BST 上严格单调，天然不重叠），深度确定 y；
- 位置、透明度、缩放都用 `requestAnimationFrame` 自己补间，节点与连线同帧更新，连线始终贴在圆边上；
- 节点入场从父节点位置弹出，离场淡出缩小；旋转时紫色描边提示旋转点；
- 平衡因子显示在每个节点右上角，0 / ±1 / ≥2 三种配色。

### 3. 播放器与算法无关

播放器只做「按索引渲染快照」，因此：

- 暂停后可以从任意一步继续；
- 上一步是免费的（快照本来就在内存里）；
- 下一次操作前如果上一个动画还没播完，会先跳到它的最后一帧，保证画面与真实树一致。

## 功能

- 插入 / 删除 / 查找，逐步展示访问路径、平衡因子计算与旋转过程；
- 插入 11 步左右、删除含「后继替换」，每一步都有一句中文解释；
- 伪代码随步骤高亮，操作结束后写入「操作历史」；
- AVL / 普通 BST 模式切换（普通模式不旋转，可用于对比退化）；
- 速度 220–1200 ms/步、平衡因子开关、随机生成、示例树、清空；
- 快捷键：空格播放/暂停，← → 单步；
- 统计：节点数、树高、是否平衡。

## 与 v1/ 的对比

| 维度 | 原版 | 本版 |
| --- | --- | --- |
| 依赖 | d3 v3 + jQuery + Bootstrap + FontAwesome CDN | 无任何依赖 |
| 动画 | 递归中 `await sleep()`，逻辑与渲染交织 | 快照 + 播放器，算法与渲染分离 |
| 控制 | 只能等它播完 | 暂停 / 上一步 / 下一步 / 跳到结束 |
| 布局 | d3 `layout.tree` + 固定 `depth * 100` | 中序定 x、深度定 y，保证不重叠 |
| 交互 | 输入框 + alert 提示 | 校验提示、状态栏、伪代码高亮、操作历史、快捷键 |
| 信息 | 只显示 key | key + bf + 高度（tooltip）+ 路径 / 旋转高亮 + 统计 |
| 正确性 | 无测试；删除里 `temp == node.left` 恒假 | Node 测试 + 浏览器冒烟测试 |
| 可维护性 | 约 450 行 main.js 混合逻辑 | 4 个职责单一的模块，约 1700 行（含注释与逐句文案） |

## 取舍与限制

- 每一步都深拷贝整棵树，节点数量很大时会变慢；这是演示工具，几十个节点足够。
- 布局是固定间距的中序排列：节点很多时舞台会横向滚动，不做自动缩放。
- 切换 AVL/BST 模式只影响之后的操作，不会重新整理现有节点（提示文案里已说明）。
- 不做 undo/redo：若要实现，直接在「操作快照」之上加一个历史栈即可，不需要重算算法。
